# Putar
**Website ini adalah aplikasi pengelola playlist musik. Pengguna dapat melihat
daftar lagu dan playlist dalam tampilan yang rapi, modern, dan nyaman dibuka
di berbagai ukuran layar (desktop maupun HP).**

# Konsep Laravel yang dipraktikkan:
- **Routing** : mengatur URL halaman di `routes/web.php`
- **Controller** : mengelola logika dan data yang dikirim ke tampilan
- **Views (Blade)** : membuat tampilan halaman
- **Blade Components** : komponen UI yang dapat dipakai ulang

# Teknologi yang dipakai
- Laravel Framework 13.40.0
- PHP
- Blade Template Engine
- HTML, CSS, JavaScript
